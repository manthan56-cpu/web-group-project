================================================================================
TECHNOLOGIES USED (STRICT COMPLIANCE WITH TEACHER INSTRUCTIONS)
================================================================================
As instructed, ONLY the required fundamental technologies were utilized.
No third-party CSS libraries, frameworks, or scripts were added.

1. HTML Tags:
   - Proper Semantic structure: <header>, <nav>, <main>, <section>, <article>, <footer>
   - Headings (<h1> to <h3>), paragraphs (<p>), unordered lists (<ul>, <li>)
   - Anchor links (<a>) for multi-page navigation across all pages

2. HTML Tables:
   - Demonstrated in courses.html:
     * Table 1: Weekly Class Schedule (<table border="1"> layout with thead, tbody, tr, th, td)
     * Table 2: Course Fee Structure (<table border="1"> demonstrating rowspan, colspan, and tfoot)

3. HTML Forms:
   - Demonstrated in register.html:
     * <form>, <fieldset>, <legend>, <label>
     * Text input, Email input, Phone input, Date picker input
     * Radio buttons (Gender selection, Batch timing selection)
     * Select dropdowns (Course track selection, Qualification selection)
     * Checkboxes (Areas of interest, Terms agreement)
     * Textarea (Address and Remarks)
     * Submit button and Reset button

4. CSS:
   - External stylesheet located at css/style.css
   - Color palette, typography, margins, paddings, box model, table borders,
     input highlights, hover effects, and clean student-grade layout.
